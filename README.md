# 网易云音乐 · MyGo Music 插件

在 [MyGo Music](https://github.com/egoist/mygo-music) 中搜索和播放网易云音乐。需要 MyGo Music 0.1.21 或更新版本，无需额外服务。

网易云 CDN 封面使用 `{size}` 模板，由主程序按列表、卡片及播放页所需尺寸请求缩略图，减少首次下载和大图解码。0.1.20 之前的主程序不支持此模板，使用前请先升级。

本分支基于 [sogud/mygo-music-netease](https://github.com/sogud/mygo-music-netease)，桌面、iOS 与 Android 使用同一份插件包；功能入口取决于各自宿主。0.1.15 修复切换到网易云确认登录时连接中断导致扫码失败：同一二维码的轮询及确认后的账号读取最多重试两次，保留待确认会话；取消、超时、接口拒绝或二维码过期后停止。其他业务请求的重试策略不变。

0.1.16 新增「音乐 MV」，展示网易云最新公开 MV。需宿主实现插件浏览与 `video`；在视频模式下由用户主动选中卡片后播放。MV 使用独立于歌曲的 ID，从同一 H.264/AAC MP4 取得声画，不尝试把其他版本的歌曲与 MV 对齐。不提供付费或受限 MV；原有歌曲播放保持不变。

0.1.17 增加公开 MV 音画同源及播放地址重新解析的回归验证，不改变取流逻辑。

## MB 会话恢复（宿主接入）

插件不连接 MB 上游，也不掌握设备令牌、恢复密钥或用户的同步开关。只在宿主已配对且用户授权同步时，由宿主调用这些可选接口，并且只给已验签、确认身份的包传入解密后的会话。

| 导出函数 | 输入与结果 |
| --- | --- |
| `exportSession()` | 在线验证本地账号后返回 `{format:1, accountId, session:{cookies}}`，无会话返回 `null`；网络错误不等于退出。只传 `MUSIC_U` 和可选 `__csrf`，不传 `NMTID`、设备 ID、账户资料或通用存储。 |
| `stageSession({format,accountId,session})` | 无本地账号且未扫码时才允许；用平台接口核对账号，返回 `{ticket,account}`，不持久化。仅一个暂存请求有效。 |
| `commitSession({ticket})` | 校验同一运行时的票据、60 秒有效期和本地状态，写入本机并返回账号。必须由宿主再次检查插件信任、绑定与用户意图后显式调用。 |
| `discardSession({ticket})` | 放弃对应票据；没有票据时调用 `discardSession()` 丢弃当前暂存（包括正在校验的请求）。 |

宿主负责端到端加密、条件更新、重装恢复以及持久化退出禁止自动恢复状态。以上接口已用模拟会话验证，不代表真实网易云账号已通过端到端迁移验收。

## 安装和使用

1. 打开 MyGo Music → 设置 → 插件 → `+` → 从 GitHub 安装，填入 `xTreeRoot/mygo-music-netease`。也可从 [Releases](https://github.com/xTreeRoot/mygo-music-netease/releases) 下载 ZIP 后从本地安装，或选择本项目文件夹。
2. 安装后，在来源选择器中选择 **网易云音乐**。
3. 点击 **登录**，用网易云音乐手机 App 扫码，访问自己的歌单和喜欢的音乐。
4. 发现页按平台歌单、喜欢的音乐、最近一周、音乐云盘固定显示真实内容预览，各区通过 **更多** 打开完整列表；独立显示每日推荐、私人雷达、个性化歌单和私人漫游。每区失败保留其他区内容，不再借用推荐歌单封面装饰导航。未登录时保留登录入口与公开推荐。

## 功能

- 歌曲、专辑、歌手、歌单和播客搜索，支持翻页。
- 推荐歌单、排行榜、歌单详情，专辑和歌手详情。
- 登录后的每日推荐、私人雷达、个性化歌单，以及持续补充歌曲的私人漫游、熟悉的歌和新发现。
- 网易云 App 扫码登录、会话恢复、个人歌单、喜欢列表、喜欢/取消喜欢。
- 将歌曲添加到自建歌单或从中移出；已存在的歌曲不会重复加入，混合批次只补充缺失歌曲。
- 标准、高音质和无损音质。
- 逐字歌词和翻译：登录后从桌面接口取回每个字的演唱时间，MyGo Music 的律动与歌词页按字点亮；无逐字数据的歌曲退回 LRC 行级歌词和翻译。
- 歌曲和播客节目的只读评论，支持分页。
- 登录后从「我的播客」读取网易云已订阅播客，浏览、分页播放节目；不修改订阅。

## 私人漫游没有歌曲时

私人漫游、熟悉的歌和新发现依赖网易云的个性化服务。关闭该服务时，账号即使已经登录，电台接口也可能返回成功状态和空歌曲列表。

请在网易云官方 App 的 **设置 → 消息和隐私 → 个性化服务** 中确认该开关已开启，然后回到 MyGo Music 点击 **开始收听**。该隐私设置由你在官方 App 中管理。若已开启但仍没有歌曲，请稍后重试。

电台卡片会显示这项前置条件。返回空列表时，插件会查询个性化服务设置；确认已关闭时，返回带有恢复说明的错误。重新开始收听会重新请求歌曲。

## 云盘、听歌排行和评论

发现音乐页新增音乐云盘、最近一周和所有时间听歌排行。云盘只读分页，不上传或删除歌曲；私有歌曲直接使用云盘元数据，播放仍以当前账号权限为准。排行保留网易云返回的顺序，当前宿主不支持播放次数列，也未实现实际收听时长上报。

评论优先显示接口提供的最多 20 条热门评论，之后按时间加载最新评论；按评论 ID 去重并分别维护显示位置与服务端位置。

支持宿主可解码的 AAC/M4A/MP4 音频，仍拒绝试听地址及无完整播放权限的结果。
